# 🚀 React Portfolio

A modern and responsive portfolio built using React to showcase my projects, skills, and work.

## ⚙️ Tech Stack

React • JavaScript • Tailwind CSS • Vite

## ✨ Features

* Not Responsive Design
* Fast & Clean UI
* Project Showcase

## 🚀 Run Locally

```bash
git clone https://github.com/zeustheking/portfolio-react.git
cd portfolio-react
npm run dev
```
